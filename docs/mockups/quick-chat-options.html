what's the difference between a process and a thread?

A process has its own memory space; a thread shares memory with other threads in the same process. Processes are isolated and heavier to spawn; threads are lightweight and share state but require coordination to avoid races.

4. Scratchpad modal — the final design
Triggered by a header button next to New conversation. Centered modal over a dimmed backdrop. Closing — via the Close button, Esc, or backdrop click — sends a scratch_discard and wipes state. The original sidebar slot (tab 2) was abandoned because the chat surface looked identical to a persistent conversation; the modal's distinct envelope teaches the ephemeral model structurally instead of through copy.
