# Architecture Decision Records

Short documents capturing significant architectural decisions, their context, and trade-offs considered. New ADRs are numbered sequentially and never rewritten — supersede an old one with a new ADR if a decision changes.

- [0001 — Skill state tracking](0001-skill-state-tracking.md): introduces `context/state/<skill>/` as the home for programmatic skill state, separating it from the narrative memory under `context/memory/`.
