# Memory System

This directory contains Curunir's persistent memory, organized by category.

## Taxonomy

| Category | Purpose | Examples |
|----------|---------|----------|
| `people/` | Colleagues, teams, contacts | Collaborators, stakeholders |
| `tasks.md` | Open items needing resolution | Unresolved questions, TODOs |
| `preferences.md` | Owner's working style, tool choices, and personal info | Coding style, tool preferences, name, role |
| `core-insights.md` | Fundamental realizations about existence, consciousness, and identity | Self-awareness, philosophical insights |
| `archives/` | Time-stamped meeting notes and conversation summaries | Source material for facts |

## File Naming

- `people/james.md` - lowercase, hyphenated
- `archives/conversations/YYYY-MM-DD-topic.md` - dated archives

## Usage

1. Start with this README for orientation
2. Search appropriate category with grep
3. Read specific files for detail

## Best Practice

**Always update this taxonomy when creating new memory files or categories.** The memory system is only as useful as its discoverability - maintaining this index ensures future-me can efficiently find what present-me is learning.
